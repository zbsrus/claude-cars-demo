# Размещение Claude Cars

Эта версия работает с одним процессом приложения, постоянной SQLite-базой и HTTPS. Папка с данными принадлежит только пользователю сервиса. В базе находятся объявления, загруженные фото и видео, переписка через форму сайта и агрегированные счётчики. Для входа Клода нужен пароль.

## Подготовка

1. Распакуйте выпуск в /opt/claude-cars. Создайте отдельного системного пользователя claude-cars. Для сервера подойдёт поддерживаемый Python 3.11 или 3.12 с venv, базой часовых поясов Europe/Brussels и поддержкой WebP в Pillow.
2. В каталоге приложения создайте окружение, установите зависимости из requirements.txt.
3. Направьте домен на хостинг. В файле /etc/claude-cars.env задайте CLAUDE_PUBLIC_ORIGIN, включая https:// и точное имя домена без пути. При размещении Caddy на этом же сервере задайте CLAUDE_TRUSTED_PROXY=127.0.0.1.
4. Для Linux с systemd приложен claude-cars.service. Он создаёт постоянную папку /var/lib/claude-cars. Укажите Caddy имя домена через переменную CLAUDE_DOMAIN или замените заполнитель в Caddyfile. Адрес, порты 80/443 и сертификат обслуживает Caddy. Приложение слушает 127.0.0.1:8000. Проверяйте конфигурацию в выбранной среде перед переключением домена.

Установка окружения из каталога приложения:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Точка входа размещения с указанными выше переменными окружения:

```sh
.venv/bin/python serve.py --data-dir /var/lib/claude-cars
```

Постоянный каталог должен быть доступен процессу на запись. При первом запуске сайт создаёт закрытый файл owner-password. Администратор передаёт пароль Клоду приватно. Альтернатива — пароль в переменной CLAUDE_OWNER_PASSWORD через хранилище секретов хостинга. В этом случае восстановление требует того же секрета. При изменении пароля прежние сессии прекращают действовать.

## Перед первым объявлением

В новой рабочей базе Z4 появляется в черновиках без года, цены, пробега и утверждений о состоянии. Заготовка содержит модель и три исходных фото. Клод сверяет их принадлежность этому автомобилю, добавляет сведения и документы, выбирает обложку и подтверждает переводы. В открытом каталоге до публикации доступны подбор и импорт. Объявление в наличии требует конечной цены в евро с обязательными расходами.

Сверьте с Клодом реквизиты, контактные каналы, условия гарантии, подбора, задатка и импорта. Для Z4 уточните историю регистрации и необходимость индивидуальной ссылки Car-Pass. Проверьте уведомление о данных с учётом реального хостинга, резервных копий и получателей. На домене проверьте главную, сертификат, карточку, осмотр, вход владельца, robots.txt, sitemap.xml и предпросмотр ссылки на устройстве. Публикация в социальных сетях остаётся самостоятельным действием владельца.

## Резервирование и восстановление

Снимок включает согласованную копию работающей базы с фотографиями и видео, а также локальные файлы доступа. Родительский каталог для резервных копий должен существовать. Каждый снимок создаётся в новой папке.

```sh
.venv/bin/python backup.py /var/lib/claude-cars /var/backups/claude-cars/snapshot-001
```

Храните снимки в закрытом зашифрованном хранилище. Периодичность и срок хранения выбирают владелец и администратор с учётом 90-дневного журнала обращений. Ограничьте или обезличьте инфраструктурные журналы с IP и параметрами обращений. Для восстановления остановите приложение, сохраните текущий каталог отдельно и восстановите снимок в пустую папку данных с владельцем claude-cars и закрытыми правами. Разверните тот же выпуск сайта и верните внешний пароль, если он был задан. После запуска проверьте каталог, фото, вход владельца и журнал. На старте приложение удалит обращения с истёкшим сроком хранения.
