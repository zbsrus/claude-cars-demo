# Claude Cars · правила интерфейса

## Компоненты и оформление

- Покупатель начинает с французской главной. Поддерживайте также NL, DE, EN и ES. Сохраняйте маршрут, выбранную машину и назначение обращения при смене языка.
- Публичная шапка, меню языков, обложка, карточки, фотогалерея и досье находятся в `web/public.js`. Используйте существующие элементы с префиксом `cc-`. Формы и журнал обращений ведёт `web/insights.js` (`ins-`), редактор объявлений — `web/owner.js` (`ow-`).
- Общие цвета, интервалы, максимальная ширина, шрифты и фокус заданы в `web/base.css`. Для крупных названий используется локальный EB Garamond, для чтения и управления — системный гротеск. Цену, пробег, статус и подпись действия сохраняйте читаемыми на узком экране.
- Пишите понятными покупателю и Клоду словами. Используйте словари соответствующего раздела в `web/`. Название Claude Cars и обозначения моделей сохраняйте в оригинале.
- Студийная Z3 на обложке представляет марку. Фото машин в продаже поступают из объявления. Показывайте цену, документы, историю и статус только для соответствующего экземпляра. Для проданной машины сохраняйте постоянную ссылку и действие для подбора похожей.

## Перенос из Figma

- Если дан точный узел, получите его контекст и изображение через Figma. Для большого узла сначала уточните структуру и ограничьте выбор нужным фреймом.
- Сопоставьте макет с действующими CSS-переменными и компонентами раздела. Фрагменты React/Tailwind переводите на штатные HTML, CSS и JavaScript проекта.
- Используйте предоставленный оригинал изображения с согласованными правами. Постоянные материалы лежат в `assets/`, загрузки Клода проходят через текущую медиатеку. Учитывайте реальные пропорции автомобиля, портретную ориентацию и кадрирование.
- Проверяйте реализованный экран по тому же состоянию и ширине. Для интерактивного элемента проверьте также клавиатуру, видимый фокус, пустое состояние, ошибку и возврат. При публикации объявления в тесте пройдите до той же машины в независимом профиле покупателя.
